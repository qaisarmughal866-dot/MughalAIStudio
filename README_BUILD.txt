Mughal AI Studio - Android source project

This archive has been flattened so it opens as one normal project folder:
MughalAIStudio/

Project files include:
- settings.gradle
- build.gradle
- gradle.properties
- app/build.gradle
- app/src/...

IMPORTANT:
This is Android source code, not a prebuilt APK.
The uploaded archive did not contain Gradle wrapper scripts or
gradle/wrapper/gradle-wrapper.jar. A compatible Android IDE/build
environment must provide Gradle 8.9+ and JDK 17, and Android SDK 35.

Open the MughalAIStudio folder (the folder containing settings.gradle)
in Android Studio / a compatible Android IDE, allow Gradle sync, then
build an APK.

The current app is a starter interface. It does not yet generate real
AI videos or voices; that requires a backend and AI service integration.

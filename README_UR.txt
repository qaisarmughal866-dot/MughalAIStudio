Mughal AI Studio — Android starter project

یہ Android Studio project ابتدائی ایپ انٹرفیس بناتا ہے:
- کہانی لکھنے کا باکس
- 2D / 3D انتخاب
- Urdu / Hindi / English
- Male / Female voice
- 30 sec / 1 min / 3 min

اہم: اس ورژن میں اصل AI ویڈیو یا آواز generate نہیں ہوتی۔ اس کے لیے محفوظ backend اور AI video/voice provider کی API keys درکار ہیں۔ API keys کو Android app میں براہ راست نہ رکھیں۔

APK بنانے کا طریقہ:
1. کمپیوٹر پر Android Studio انسٹال کریں۔
2. اس ZIP کو extract کریں۔
3. Android Studio میں "Open" سے MughalAIStudio فولڈر کھولیں۔
4. Gradle sync مکمل ہونے دیں۔
5. Build > Build Bundle(s) / APK(s) > Build APK(s) منتخب کریں۔
6. APK فون میں منتقل کر کے انسٹال کریں۔

یہ project Android Studio کے لیے starter source ہے، پہلے سے تیار APK نہیں۔
